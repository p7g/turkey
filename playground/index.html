Turkey Playground

The Turkey compiler, compiled to WebAssembly, runs in your browser. Nothing is sent to a server. New to Turkey? Take the tour.






  

  





Tab inserts a tab; press Escape and then Tab to move on from the editor. Problems are underlined as you type; F8 and Shift+F8 (Fn+F8 on a Mac) move to the next and previous one, and the caret on one shows its message.



  
  
  
  





    
  
  • The first visit downloads the compiler (about 6 MB compressed); later visits use the browser's cache. A compile takes a second or two, longer for programs that import large libraries.
    • 
  
  • A run stops after the time limit, 10 seconds by default. Output appears as the program writes it, so a program stopped by the limit or by Stop keeps what it printed. The pane keeps the last 1 MB.
    • 
  
  • Tasks run one at a time, on the run's one thread: a task that computes without waiting holds it until it finishes.
    • 
  
  • A program is main.gob and any modules beside it: Add file makes one, and its name is its module's path, so Shapes/Circle.gob is import Shapes.Circle. Run compiles every file; Format lays out the one shown.
    • 
  
  • Share puts every file, compressed, in the link after the #, which browsers never send to a server. A long program makes a long link, and some apps cut long links short.
    • 
  
  • Choosing an example replaces what is in the editor. Undo (Ctrl+Z or Cmd+Z) brings your text back in browsers that keep the editor's undo history.
    • 
  
  • Opening a share link replaces what is in the editor, and Undo does not bring it back.
