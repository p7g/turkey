Turkey Playground

The Turkey compiler, compiled to WebAssembly, runs in your browser. Nothing is sent to a server.

Tab inserts a tab; press Escape and then Tab to move on from the editor.

  • The first visit downloads the compiler (about 6 MB compressed); later visits use the browser's cache. A compile takes a second or two, longer for programs that import large libraries.
  • A run stops after the time limit, 10 seconds by default. Output appears when the program ends, so a program stopped by the limit or by Stop shows none.
  • Programs that spawn tasks or use channels cannot run here yet: they trap, and the trap message is shown.
  • Share puts the source, compressed, in the link after the #, which browsers never send to a server. A long program makes a long link, and some apps cut long links short.
